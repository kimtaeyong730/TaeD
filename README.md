## About Me

I'm interested in building tools that make difficult security work more repeatable:

- reverse engineering workflows with IDA Pro and LLM assistance
- fuzzing pipelines for crash discovery and root-cause analysis
- CTF-style binary analysis and exploit reasoning
- web/security experiments and small automation projects
